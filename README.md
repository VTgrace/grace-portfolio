# Grace's Portfolio
A repository to store the code for my portfolio website.  
This website was built using React + TypeScript + Vite.  
It is currently a W.I.P.  

Visit the website [here](https://VTgrace.github.io/grace-portfolio)!

## Background
This project was built off a template providing a minimal setup to get React working in Vite with HMR and some Oxlint rules.  
See the [Oxlint rules documentation](https://oxc.rs/docs/guide/usage/linter/rules) for the full list of rules and categories.
